# arvin-portfolio

Source of [arvinroeslim.my.id](https://arvinroeslim.my.id), the portfolio of Arvin Roeslim, a mobile developer. Built with Astro as a static site. Content lives in this repo, and a `v*` tag deploys it to my homelab with Docker.

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # static output in dist/
npm test         # checks the built site
```
